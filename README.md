# 외국인 미납통행료 안내페이지 V5.4.5

## 적용 방법
1. 이 ZIP의 압축을 풉니다.
2. 기존 foreign-guide 저장소에서 index.html을 같은 위치의 새 파일로 교체합니다.
3. assets 폴더의 파일을 같은 assets 위치에 추가·교체합니다. 폴더 이름을 바꾸지 않습니다.
4. .nojekyll은 그대로 포함합니다. 기존에 있던 다른 파일을 모두 삭제할 필요는 없습니다.
5. 사이트 배포가 끝난 뒤 기존 주소를 다시 열고, 화면 하단 V5.4.5 표시를 확인합니다.

기존 주소: https://korea-hipass-toll-guide.github.io/foreign-guide/
메인 진입 주소: https://korea-hipass-toll-guide.github.io/foreign-guide/#language-ko
주소와 QR 연결은 유지됩니다. ZIP 자체를 저장소에 올리는 것이 아니라, 압축을 푼 파일을 올립니다.

## 이번 변경
- 중국어·영어·베트남어·러시아어·네팔어 센터 검수 회신을 반영했습니다.
- 영어 FAQ의 잘못 붙여넣어진 문장, 러시아어 기관명, 중국어 조치 가능성 표현 등은 기능·의미에 맞게 조정했습니다.
- 우즈베크어·몽골어·미얀마어는 AI 추가검토를 반영했습니다. 원어민 검수가 완료된 것으로 표시하지 않습니다.
- 기능 수정 때문에 추가·변경된 외국어 안내문 역시 센터 재검수 전 문구입니다.
- 휴대폰/브라우저 뒤로가기·앞으로가기 및 스크롤 복원 처리를 추가했습니다.
- 한글 미선택 기본값을 제거하고, 직접 한글을 선택해야 복사되도록 했습니다.
- 복사 후 입력 변경 경고, 같은 차종 재선택 시 문자 유지, 입력 중 미리보기, 다른 숫자 표기 정규화를 적용했습니다.
- 복사 실패 시 직접 선택하여 복사할 수 있는 입력칸을 제공합니다.
- 비회원 본인인증 경로, 최근 미납 반영 지연 및 안내페이지/실제 조회 사이트 구분을 보완했습니다.
- 기존 CI·캐릭터·승인된 ①②③ 안내 이미지와 주요 배치, 전화·카카오·공식사이트 연결주소를 유지했습니다.

## 검증 범위
동봉 소스를 읽고 JavaScript 구문검사, 로컬 참조파일 존재 확인을 수행했습니다.
Chromium의 오프라인 문서 실행환경에서 뒤로가기/앞으로가기, 화면·언어·스크롤 복원, 입력 및 복사 흐름을 검사했습니다.
320·390·768px 너비에서 9개 언어의 5개 콘텐츠 화면 활성화와 가로 넘침 여부를 확인했습니다.
클립보드 성공/실패는 모의 API를 사용했습니다. 휴대폰 실제 클립보드, 인앱브라우저, 실제 배포 네트워크 로딩,
본인인증, 차량 미납조회, 납부, 전화발신 및 상담 전송은 시험하지 않았습니다.
전체 브라우저 호환성 또는 번역 정확성을 보증하는 검증은 아닙니다.

## 개인정보 및 기능 범위
차량번호는 현재 문서의 메모리에서 조합·복사합니다. 서버 전송, URL 기록, localStorage/sessionStorage 저장은 하지 않습니다.
브라우저 방문기록에는 화면·언어·이동순서·스크롤 위치만 저장합니다. 새로고침하면 입력한 차량번호는 초기화됩니다.
이 페이지는 안내 및 입력 보조입니다. 실제 조회·납부는 공식 Hi-Pass 사이트에서 진행합니다.
