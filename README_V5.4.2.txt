[유지 사항]
현재 사이트의 9개 언어: 한국어, 영어, 중국어, 베트남어, 러시아어, 우즈베크어, 몽골어, 미얀마어, 네팔어
※ 태국어·인도네시아어가 들어 있는 과거 패키지의 언어목록으로 되돌리지 않았습니다.
한국어 본문, 주요 색상·화면 구성, 이미지, 번호판 도우미, 전화번호, 채팅 링크, 통역 '관계기관 협의 중' 유지.
외국어 문장이 길어지는 경우 글자 잘림을 방지하는 줄바꿈 보완만 적용.
이미지 안의 한국어는 공식 화면을 설명하는 참조 화면이므로 변경하지 않았습니다.

[이번 수정]
한국어 본문에 대응하는 외국어 8개 언어를 전체 대조했습니다.
각 언어의 본문 63개, 입력 도우미 19개, 부가안내 29개: 총 111개 핵심 문구.
상단 이동, 입력란, 설명 그림의 접근성 레이블 및 예시 브라우저 메뉴도 각 언어로 표시.
중국어는 제공된 'QR홍보리플릿_중국어_검수용 中文(2).hwp'의 대응 용어와 수정 의견을 반영.
웹사이트 기능과 다른 리플릿 전용 문구는 그대로 복사하지 않았습니다.
통행료 10배/최대 10배 혼동, 회원가입 조건, 미납 건수와 금액 누락, 납부계좌와 로그인 계정 혼동 등을 수정.
HTML translate="no" 및 google notranslate 설정을 유지하여 안내페이지 자체의 재번역을 방지하도록 요청.
외국어 번역은 이 사이트의 언어 선택 메뉴에서, 공식 Hi-Pass 웹페이지 번역은 이동한 사이트에서 사용.

[확인 범위]
로컬 Chromium: 9개 언어 전환, 한국어 복귀, FAQ, 차량번호 조합/복사, 번역 탭 전환 확인.
가로 360/390/760/1280px × 9개 언어 × 5개 상세/메뉴 화면 = 180개 화면의 가로 넘침 및 이미지 로드 검사.
실제 Android/iPhone 하드웨어와 모든 브라우저의 자동번역 차단까지 확인한 것은 아닙니다.
전화 연결 이후 상담, 외부사이트 로그인·납부 완료는 테스트하지 않았습니다.
원어민 전체 검수 완료를 뜻하지 않습니다. 제공된 중국어 검수 항목 외의 문구는 AI 대조수정입니다.
